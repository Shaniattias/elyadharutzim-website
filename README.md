# אתר אל יד חרוצים בע"מ

האתר של elyadharutzim.com. אתר סטטי שמתארח ב-GitHub Pages.

## מבנה התיקיות

```
/                          ← השורש של האתר (מה שעולה ל-GitHub)
├── index.html             ← העמודים המוכנים. נוצרים אוטומטית מ-_src, לא עורכים אותם ישירות
├── about.html, trade.html, brands.html, food.html, steel.html, mining.html, buy.html, contact.html
├── terms.html, privacy.html, cookies.html, accessibility.html, 404.html
├── en/  fr/  de/  es/     ← אותם עמודים באנגלית, צרפתית, גרמנית וספרדית (נוצרים אוטומטית)
├── CNAME                  ← מחבר את הדומיין elyadharutzim.com. לא למחוק!
├── robots.txt, sitemap.xml← בשביל גוגל
│
├── assets/
│   ├── css/               ← עיצוב, מחולק לקבצים לפי נושא. נטענים לפי סדר המספרים
│   ├── js/
│   │   ├── config.js      ← הגדרות: קישורי פייסבוק ולינקדאין
│   │   ├── site/          ← התנהגות משותפת לכל העמודים (תפריט, עוגיות, נגישות...)
│   │   └── home/          ← הסצנות של דף הבית (סרטון, מכונות, משאית, קרטון)
│   ├── img/
│   │   ├── photos/        ← תמונות התחומים (נמל, מזון, פלדה, כרייה...)
│   │   ├── team/          ← תמונות הבעלים
│   │   ├── brands/        ← קיר המותגים
│   │   ├── story/ truck/ box3d/  ← החלקים של סצנות דף הבית
│   │   └── favicon.svg
│   ├── fonts/             ← הגופן Open Sans Hebrew
│   └── video/opening.mp4  ← סרטון הפתיחה (איכות מקורית)
│
└── _src/                  ← קוד המקור של העמודים (לא מתפרסם באתר)
    ├── site.json          ← פרטי החברה, התפריט וכרטיסי "עוד באל יד חרוצים"
    ├── components/        ← רכיבים משותפים: כותרת, תחתית, באנר עוגיות, תפריט נגישות...
    ├── pages/             ← התוכן של כל עמוד (בעברית, שהיא המקור)
    ├── i18n/              ← מילוני התרגום: en.json, fr.json, de.json, es.json
    └── build.py           ← מרכיב את העמודים מהרכיבים ומהתוכן
```

## איך עמוד נבנה

כל עמוד מורכב מרכיבים, לפי הסדר:

```
head → header → כותרת העמוד → התוכן מ-_src/pages → עוד באל יד חרוצים → footer → עוגיות → נגישות → סקריפטים
```

בראש כל קובץ ב-`_src/pages` יש הערה עם הגדרות העמוד: כותרת לגוגל, תיאור, הכותרת הגדולה, תמונה ופירורי לחם.
עמודים משפטיים (`layout: legal`) מקבלים תוכן עניינים אוטומטי מכותרות ה-h2.

## שפות

האתר קיים בחמש שפות: עברית (בתיקייה הראשית), ואנגלית, צרפתית, גרמנית וספרדית בתיקיות en, fr, de, es.
בכל עמוד יש כפתור גלובוס בכותרת שעובר לאותו עמוד בשפה אחרת, ובתפריט הטלפון יש שורת שפות.

העברית היא המקור. כל טקסט בעברית מתורגם לפי המילונים ב-`_src/i18n`
(המפתח הוא הטקסט בעברית והערך הוא התרגום). כשמשנים או מוסיפים טקסט בעברית,
מוסיפים את התרגום שלו לארבעת המילונים ומריצים את הבנייה. אם חסר תרגום, הבנייה עוצרת ומציגה את הטקסטים החסרים.
בתנאי השימוש בשפות הזרות כתוב שבמקרה של סתירה, הנוסח העברי קובע.

## שינויים נפוצים

| מה רוצים לשנות | איפה |
|---|---|
| טלפון, מייל, כתובת, ח.פ. | `_src/site.json`, ואז להריץ את הבנייה |
| פריט בתפריט | `_src/site.json` (המפתח `menu`), ואז להריץ את הבנייה |
| קישורי פייסבוק ולינקדאין | `assets/js/config.js` (לא צריך בנייה) |
| טקסט בעמוד | הקובץ של העמוד ב-`_src/pages`, התרגומים ב-`_src/i18n`, ואז להריץ את הבנייה |
| התחתית או הכותרת | `_src/components/footer.html` או `header.html`, ואז להריץ את הבנייה |
| צבעים וגופנים | `assets/css/02-base.css` ו-`13-theme-light.css` |

הרצת הבנייה (מתוך התיקייה הראשית):

```
python3 _src/build.py
```

## העלאה ל-GitHub

מעלים את כל התוכן של התיקייה הזו לשורש המאגר, כולל `assets` ו-`_src`.
הקובץ `CNAME` חייב להישאר, אחרת הדומיין מתנתק.
התיקייה `_src` לא מתפרסמת באתר (GitHub Pages מדלג על תיקיות שמתחילות בקו תחתון).
